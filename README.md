Project Overview

This project introduces core Python programming concepts through a series of interactive, text-based applications. Each mini-project simulates real-world scenarios such as purchasing items, managing tasks, booking tickets, and testing knowledge through quizzes. The goal is to strengthen foundational programming skills while building practical, user-driven applications.

⸻

Project Objectives

	-	Develop a strong understanding of Python fundamentals
	-	Practice writing clean, readable, and modular code
	-	Apply programming logic to real-world business and user scenarios
	-	Improve problem-solving and debugging skills
	-	Build confidence working with loops, conditionals, data structures, and user input

Projects Included 
	
	1. Vending Machine program
		- Displays available snacks and drinks with prices
		-Allows users to select multiple items in a loop
		-Ends when the user types done
		-Generates a receipt showing selected items and total cost

Skills Practiced 
loops, input(), conditionals, lists/dictionaries, sum(),print formatting 

	2. Simple Grocery Cart Checkout
		- Uses predefined grocery price list
		-Allows users to add items and specify quantities
		-Calculates subtotals and final total
		-Handles invalid item entries 

Skills Practiced 
dictionaries, loops, input(), math operations, error handling, formatting

	3.TO-DO-List App(Text-Based)
		-Add tasks with priorities
		-View, delete, and mark tasks as complete
		-Runs continuously until the user exits
		-Display a summary of completed vs pending tasks

Skills Practiced 
lists, string parsing, loops, CRUD operations, user input handling

	4. Movie Ticket Booking Simulation
	   - Displays movies, showtimes, and ticket prices
 	  - Allows multiple bookings in one session
  	 - Calculates TOTAL COST for all bookings
   	-Provides booking summary at the end

Skills Practiced 
nested dictionaries, loops, conditionals, calculations

	5. Quiz Game
  	 -Asks 5-10 predefined questions
  	 -Tracks user answers and score
 	  -Displays correct answers for missed questions

Skills Practiced
loops, dictionaries, comparisons, counters, print formatting

Conclusion

This project highlighted the importance of input validation, clean program structure, and appropriate data structures when developing 	interactive Python applications. Real-world simulations reinforced core programming concepts and improved problem-solving skills.
